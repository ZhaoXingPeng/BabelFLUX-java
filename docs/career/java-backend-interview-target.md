# Java 后端面试能力映射

本项目按大厂 Java/全栈校招常见要求组织，重点覆盖：

- Java 21、Spring Boot、REST/WebSocket、分层架构和可测试性；
- Redis 缓存与分布式会话、RabbitMQ 异步削峰和可靠投递、Elasticsearch 报告检索；
- 并发容器、有限队列、背压、超时、幂等、重试和优雅降级；
- 数据结构与算法：有界滑动窗口、哈希索引、线性复杂度事件聚合；
- 工程流程：Issue -> 小分支 -> 小 PR -> 契约测试 -> STAR 性能/缺陷记录。

后续每个迁移切片都必须补充一项可面试叙述的结果：问题规模、设计取舍、
故障边界、指标变化和回滚方案。没有实测数据时明确标注“待测”，不虚构结果。
